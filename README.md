# ❤️ Heart Stroke Prediction Using Machine Learning

## 📌 Project Overview

This project is a **Machine Learning-based Heart Stroke Prediction system** that predicts the likelihood of heart stroke based on user-provided health-related information.

The project includes data preprocessing, feature scaling, machine learning model training, model evaluation, and a **Streamlit web application** for making predictions.


##  Objective

The main objective of this project is to use machine learning techniques to analyze health-related data and build a predictive model that can assist in identifying the possibility of heart stroke.

 **Note:** This project is developed for educational and demonstration purposes and should not be used as a medical diagnostic tool.


## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Exploratory data analysis and visualization
* **Scikit-learn** – Machine learning
* **Joblib** – Saving and loading trained models
* **Streamlit** – Web application


## 🤖 Machine Learning Models

The project explores different machine learning classification algorithms, including:

* Logistic Regression
* Support Vector Machine (SVM)
* Decision Tree
* Random Forest
* K-Nearest Neighbors (KNN)
* Naive Bayes

The final application uses the trained **KNN model** for prediction.
